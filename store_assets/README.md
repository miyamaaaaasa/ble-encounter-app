# store_assets — Google Play ストア掲載素材

Play Console の「ストアの掲載情報」にそのままアップロードできる素材。

| ファイル | 用途 | 規格 |
|---|---|---|
| `play_icon_512.png` | アプリアイコン | 512×512 PNG・不透明（Playが角丸を適用） |
| `play_feature_1024x500.png` | 機能グラフィック | 1024×500 PNG |
| `shot_1_today.png` | スクショ: きょうの広場 | 1260×2730 |
| `shot_2_plaza.png` | スクショ: みんなの広場 | 1260×2730 |
| `shot_3_profile.png` | スクショ: プロフィール | 1260×2730 |
| `shot_4_editor.png` | スクショ: ドット絵エディタ | 1260×2730 |
| `shot_5_badge.png` | スクショ: バッジずかん | 1260×2730 |

スクリーンショットは A202SH（1260×2730）の実機から取得したもの。
Playの要件（最短辺320px以上・最長辺3840px以下・最低2枚）を満たす。

## 作り直す場合

アイコンと機能グラフィックは `assets/icons/tab_today.png` を元に生成している。
元画像の四隅に薄い灰色の背景が入っているため、塗りつぶしで透過してから
アプリのクリーム色（#FBF3E4）に合成している。
