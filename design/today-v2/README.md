# Today UI 改訂モック v2

モック作成日: 2026-10-05。元画像は検討用の静止画。その後の実装状況は下記を参照。

## 実装状況 — beta1.13.1+54

同日、ユーザーの「既存機能を変えず、UIだけ実装」指定に基づきTodayと共通ドックを改修。人数表示の省略案は採用せず、既存情報を維持した。

`assets/today/plaza_light.png` と `plaza_dark.png` は装飾背景のみ。相手のドット絵・名前・一言・状態・再会ラベル・曖昧な時間帯は既存データから動的に表示する。ゲート、通知、保存、履歴、スワイプの既存処理を維持。

`implemented-light.png` / `implemented-dark.png` はFlutterウィジェットテストから撮影した実装画面。人物はテスト用ドット絵・仮名であり実際のユーザーデータではない。Pixel 10のリリースAPKも両テーマで巡回済み。実機・iOSの確認は未実施。

背景は組み込み画像生成ツールで作成。原画の友人アイコンは加工せず別名で同梱し、従来のアプリアイコンを置換していない。

## 前回案の修正

- 7タブを「今日・広場・ゲーム・バッジ・カケラ・じぶん・設定」の順で維持。
- タイトルのTodayアイコン、スキャン状態、お知らせの閉じる操作、開門前の気配を維持。
- 中央人物の一言・名前に、状態、再会回数の抽象ラベル、曖昧な時間帯を復元。
- 未定義だったプロフィールボタン、ページ位置の点、気配と履歴の矢印を除去。
- じぶんタブは自作ドット絵を表示。未作成時にだけ既定アイコンを使用。
- 開門は既存の正方形アセットを参照。朝09:00・昼12:00・夜21:00、開封・確認済み・カウントダウンの役割を維持。
- 履歴の日付と再会ラベルを復元。履歴には架空の一言や新しい操作を追加しない。
- ドット絵は正方形の作品として全体を表示。背景から切り抜ける人物画を前提にしない。
- 絵文字を使わず、正式アセット・小さな線画記号・文字で表現。
- ライト／ダークを同じ構成とし、夜も作品の元の色を維持。

## 意図的な提案と制約

現行Todayは人数を数字で表示するが、恒久ルールでは生の数値を隠す。本案は人数の数字を人物の並びで表現する提案。人数を表す抽象ラベルの閾値は未確定で、新しい集計ロジックは実装しない。再会回数には既存の「見かけた」「よく見る」等を使う。

画像は縦スクロールする内容を展開した見本。履歴まで小さい端末の一画面に収まる保証はしない。生成画像内のアイコンは参照描画であり原画のピクセル一致は保証しない。実装時は原ファイルを直接使用する。

## 実装時に保持・確認する状態

- 出会いなし、おやすみ中、お知らせなし、気配なし。
- 出会いなし／未確認／確認済みの各ゲート、21時以降の翌朝ゲート。
- 開門前の相手情報は表示しない。開封カード・スキップ・完了の既存導線を保持。
- 横スワイプ・スナップ・左右人物タップによる中央移動・控えめな待機と新規出会い演出。
- 長い名前・一言、拡大文字、小さい画面、iPad、横向き、任意の自作ドット絵。
- 秒更新・受信・閉じる・スクロール・復元・通信失敗の動作。

静止画では操作、コントラスト比、実機でのレイアウトやアクセシビリティを検証できない。実装QAで確認する。
