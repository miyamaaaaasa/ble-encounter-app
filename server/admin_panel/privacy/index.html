プライバシーポリシー

アプリ名: はじめましてこんにちは（Bluetoothですれ違った人との出会いを楽しむコミュニティゲーム）

最終更新日: 2026年10月7日

このアプリはあなたが誰であるかを知りません。 メールアドレス・電話番号・氏名の登録は不要で、一切お尋ねしません。 またGPSなどの位置情報は使用せず、あなたがどこにいたかを記録することもありません。

1. 収集する情報

アプリの動作のために、次の情報をサーバーに保存します。 プロフィールはあなた自身がアプリ内で設定したものです。ほかに匿名の接続情報と、復元に必要な暗号化データを保存します。

項目内容目的
匿名ID アプリが自動生成するランダムな文字列 あなたの設定を保存しておくため
表示名 あなたが入力したニックネーム（本名である必要はありません） すれ違った相手に表示するため
アバターの色・ドット絵 あなたが選んだ色と、描いた16×16のドット絵 同上
自己紹介 あらかじめ用意された選択肢から選んだ4項目（状態・趣味・詳細・ひとこと） 同上。自由入力ではないため、個人を特定する文章は保存されません
バッジの獲得状況 アプリ内で獲得したバッジの段階 同上
すれ違い用トークン 24時間で入れ替わるランダムな文字列 すれ違いの検出。48時間経過後の定期処理で削除します
最終アクセス日時 アプリが最後にサーバーへ接続した日時 利用状況の把握（何人が使っているかの集計）
匿名の相互すれ違い記録匿名IDの組み合わせと検出日時。場所は含みません片方向だけのBluetooth検出を補完するため。48時間経過後の定期処理で削除します
暗号化した復元用データプロフィール、端末内のすれ違い履歴、ドット絵、図鑑・カケラ・バッジなどの保存データを圧縮・暗号化したもの管理者が削除したアカウントを復元するため。解読用の鍵は本人の端末にだけ保存され、サーバーへ送信されません

2. 収集しない情報

Bluetoothと位置情報の権限について

このアプリは近くの端末を見つけるためにBluetoothを使用します。 Android 11以前の端末では、OSの仕様上Bluetoothでの検索に 位置情報の権限が必要になるため、権限の許可をお願いすることがあります。 ただしこれはOSが求めるものであり、アプリが実際に位置情報を取得・送信することはありません。 Android 12以降の端末では、この権限は要求しません。

すれ違いの記録について

すれ違いの履歴は端末に保存します。復元のため、端末で暗号化したコピーをサーバーに送ります。 そのコピーはサーバー側では解読できません。また、検出を補う匿名の相互記録を短期間保存します。 GPSやすれ違った場所は保存しません。端末の鍵を失った場合、暗号化したコピーは復元できません。

3. 情報の保存場所と期間

  • データは日本国内のサーバーに保存されます。
  • 通信はすべてHTTPSで暗号化されています。
  • 障害に備え、暗号化した状態で外部のクラウドストレージにバックアップを保管しています。暗号化されているため、保管先の事業者が内容を読むことはできません。
  • すれ違い用トークン・相互記録は48時間経過後の定期処理で削除します。通常のプロフィール・復元用データはアカウントが存続する間保存します。
  • 管理者が削除したアカウントは直ちに利用停止し、30日間復元可能な状態で保持します。期限後、サーバーの定期処理（1時間ごと）で本体データを完全削除します。
  • 既存の世代バックアップは本体の削除と同時には消えません。サーバー内のバックアップは日次7世代（手動分を含む場合は最大14世代）、外部の暗号化バックアップは30日を上限とする保持方針で順次削除します。

4. 第三者への提供

収集した情報を第三者へ販売・提供することはありません。 広告配信や分析のための外部サービスも利用していません。

例外として、法令に基づく開示請求があった場合にのみ、必要な範囲で対応することがあります。

5. データの削除方法

アプリから削除する

アプリ内の 設定 → データ管理 → サーバーのデータを削除 から、いつでもご自身で削除できます。削除すると、表示名・アバターの色・ドット絵・ 自己紹介・バッジの獲得状況・復元用データがサーバーの本体DBから消去されます。世代バックアップは上記の保持期間に従って削除されます。

アプリを削除した場合

端末内のデータ（すれ違いの記録など）はすべて消えます。 サーバー側のデータを消したい場合は、アンインストールの前に上記の削除操作を行ってください。

問い合わせによる削除

アプリを既に削除してしまった場合など、ご自身で操作できないときは、 下記の連絡先までご連絡ください。ご本人確認のうえ対応いたします。

6. お子さまの利用について

このアプリは特定の年齢層を対象とした設計にはしていません。 ニックネームは他の利用者に表示されるため、本名や学校名など個人が特定される情報は入力しないでください。 保護者の方で、お子さまの情報の削除をご希望の場合は、下記の連絡先までご連絡ください。
